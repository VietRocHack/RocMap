# 2026-09-09

## 01:40 — Re-hosted RocMap onto `vietrochack-lab`, added agentic dev-env scaffolding

User wants RocMap (built during a VietRocHack hackathon, previously wired to two
different teammates' personal Firebase/GCP projects and GitHub forks) permanently
re-hosted under the team's own `vietrochack-lab` GCP project, live at
`rocmap.vietrochack.com`, with no visual/UI changes.

**Backend** (`backend/`): `direction.py`'s `load_data()` no longer fetches
`nodes.json`/`edges.json`/`halls.json` over HTTP from a teammate's personal GitHub
fork on every request — it reads bundled local JSON in `backend/data/` instead
(copied from the root `data/` folder). `main.py`'s `get_image_url()` no longer
points at a different teammate's personal Firebase Storage bucket — it returns a
same-origin relative path (`/images/{name}`), since images now ship as static
Hosting assets under `front-end/roc-map/public/images/`
([ADR 0002](../adr/0002-backend-reads-bundled-local-data.md),
[ADR 0003](../adr/0003-images-as-static-hosting-assets.md)). Dropped the now-unused
`requests` dependency.

**Frontend** (`front-end/roc-map/`): `App.js` now calls a relative
`/api/findDirection` instead of the old hardcoded personal-project Cloud Function
URL. Deleted the dead `src/utils/fetchData.js` debug file (unused, pointed at the
same dead URL). Also removed the stray root `package.json`/`package-lock.json`
(a single unused `@syncfusion` dependency, unrelated to the real app manifest).

**Deploy topology** ([ADR 0001](../adr/0001-deploy-topology.md)): Cloud Functions
gen2 (not Cloud Run — the backend is already a single `functions_framework`
function, no rewrite needed) + Firebase Hosting, same GCP project, same origin via
a Hosting rewrite (`/api/**` → the function) — no separate API subdomain, no CORS.
Added `firebase.json`/`.firebaserc` targeting a **dedicated** `vietrochack-rocmap`
Hosting site (not the project's default site) mapped to a `rocmap` target, per the
multi-app resource-siloing convention the user asked for since `vietrochack-lab`
will host other hackathon projects too
([ADR 0004](../adr/0004-resource-siloing-in-shared-project.md)).

Ran the actual deploy: enabled Firebase + the Cloud Functions/Run/Build/Artifact
Registry/Eventarc APIs on `vietrochack-lab`, created the `vietrochack-rocmap`
Hosting site, deployed `rocmap-findDirection` (gen2, Python 3.12, us-central1),
built and deployed the frontend to `hosting:rocmap`. **Verified live**, not just
via unit tests: curled the deployed function directly (got a real route back,
